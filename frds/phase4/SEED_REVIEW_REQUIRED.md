# Phase 11.4 Seed Semantics Review Register

This pack is executable and deterministic, but two categories of business semantics were not recoverable as exact frozen values from the currently available source context. They are therefore not silently invented.

## REVIEW-001 — Per-Moment-Type Quick Add subsets

The known master Quick Add sets for Shared Experience, Shared Purchase, and Shared Living were applied to each listed Moment Type in those families. Earlier work indicated that per-type subsets had been discussed, but the exact historical subset matrix was not recoverable in the active source context. Review V019 against the product/Figma catalogue before production RC if subtype differences are required.

## REVIEW-002 — Analytics formulas and thresholds

V022 seeds metric identities, semantic input contracts, dependencies, and DRAFT version records. Exact numeric formulas, time windows, evidence minima, and thresholds were not recoverable, so no metric version is activated and no threshold row is fabricated. These must be approved before V030 can consider the intelligence layer production-ready.

## REVIEW-003 — Governance policy rule bodies

V023 seeds stable policy identities and DRAFT default-deny version envelopes. Exact monetary cut-offs, approval routes, consent combinations, lifecycle exceptions, and policy rules were not recoverable as frozen values. They remain DRAFT and must be approved before production activation.

## REVIEW-004 — Baseline role bundles

V020 provides a coherent least-privilege baseline for the system role names used throughout Phase 10. If a separate Phase 6.6 role-permission matrix exists outside the currently available source context, reconcile it before production RC.
